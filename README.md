# Calculator App

A simple and responsive calculator built using **HTML, CSS, and JavaScript**. This application performs basic arithmetic operations with a clean and user-friendly interface.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Clear all calculations (AC)
* Delete last entered digit (DEL)
* Decimal number support
* Responsive design for desktop and mobile devices
* Real-time display updates

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## How to Run the Project

1. Download or clone the repository:

```bash
git clone https://github.com/your-username/calculator-app.git
```

2. Navigate to the project folder:

```bash
cd calculator-app
```

3. Open `index.html` in your browser.

No additional installation or dependencies are required.

## Usage

1. Click the number buttons to enter values.
2. Select an arithmetic operator (+, -, ×, ÷).
3. Enter the second number.
4. Press `=` to view the result.
5. Use `AC` to clear the calculator.
6. Use `DEL` to remove the last entered character.
